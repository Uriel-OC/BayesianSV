# Estructura

- Carpeta `data/`. Los archivos de datos utilizados en el código para la
    estimación.
- Carpeta `scripts/`. Los códigos separados dependiendo la funcionalidad.

Para ejecutar los scripts, por ejemplo el de la función $s$ sintética, se debe
escribir en la consola
```bash
julia --project=./scripts scripts/synthetic.jl
```
desde la raíz del proyecto.
